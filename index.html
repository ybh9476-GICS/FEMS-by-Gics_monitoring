    사용 도움말

    01 화면 개요

    대지 위에 건물과 설비를 배치하고, 층별 공간과 전력 연결을 관리하는 편집기입니다.

    각 항목의 이미지는 실제 화면에서 필요한 부분만 캡처한 예시입니다. 이미지를 클릭하면 크게 볼 수 있습니다. 프로젝트 이름과 수치는 작업에 따라 다릅니다.

    상단바
    프로젝트를 새로 만들고, 열고, 저장합니다. 기본 프로젝트 교체와 도움말도 여기에 있습니다.
    좌측 · HIERARCHY
    프로젝트·대지·건물·층·설비의 계층입니다. 이름이나 코드로 검색하고, 드래그하여 소속을 바꿉니다.
    중앙 · 작업 화면
    3D View와 평면도로 배치를 확인하고, 계통도로 전력 연결을 확인합니다. 배치 화면의 상단 경로 표시에서 대지·건물·층 사이를 이동합니다.
    우측 · PROPERTIES
    선택한 객체의 정보를 확인합니다. 수정 가능한 이름·위치·크기와 연결 설정을 변경합니다.
    하단 · 에셋 창
    기본 설비·추가 설비·건물·층 모델을 선택합니다. ‘에셋 등록’으로 GLB 모델을 추가합니다.

    02 시작 순서

    1. 프로젝트를 열거나 새 프로젝트를 만듭니다.
    2. 대지 크기를 정하고, 필요한 건물과 층을 구성합니다.
    3. 설비를 배치한 뒤 계층과 전력 연결을 설정합니다.
    4. 배치와 연결선을 확인하고 .fems 파일로 저장합니다.

    03 프로젝트와 저장

    새로 만들기 · 열기 · 이름

    • 새 프로젝트: 빈 대지로 시작합니다. 현재 프로젝트의 추가 에셋 목록도 초기화됩니다.
    • 프로젝트 열기: .fems 파일의 배치·연결·추가 에셋을 불러옵니다.
    • 프로젝트 이름: 좌측 최상위 항목을 선택하고 우측에서 수정합니다. 저장 파일명과는 별개입니다.

    대지 정보 편집

    좌측 계층에서 대지를 선택하면 우측에 이름과 크기가 표시됩니다. 이름은 Enter로 적용하고, 가로·세로는 적용 버튼으로 변경합니다. 면적은 가로×세로로 계산합니다.

    파일 저장과 자동 저장

    • 프로젝트 저장: 도면 상태와 프로젝트에 등록된 추가 에셋을 .fems 파일에 함께 보관합니다.
    • 자동 저장: 현재 브라우저의 같은 접속 주소에서 작업을 복원합니다. 다른 브라우저나 GitHub 페이지로 자동 공유되지는 않습니다.
    • 다른 PC로 옮기거나 중요한 작업을 보관할 때는 .fems 파일을 저장하세요.

    기본 프로젝트 교체

    현재 도면과 추가 에셋 목록을 프로젝트의 기본 구성으로 저장합니다. 로컬 서버에서 실행하며, GitHub 반영에는 별도 푸시가 필요합니다.

    기본값 덮어쓰기는 실행 취소로 되돌릴 수 없습니다. 필요한 현재 작업은 먼저 .fems로 저장하세요. ‘이전 작업 백업’은 과거 변경 직전에 자동 보관된 도면입니다.

    04 작업화면과 보기 모드

    작업화면 상단에서 3D View · 평면도 · 계통도를 선택합니다. 같은 프로젝트를 서로 다른 방식으로 보여줍니다.

    3D View · 입체 배치
    건물 외형, 층 높이, 설비 크기와 공간 관계를 확인합니다.
    평면도 · 위에서 보는 배치
    설비의 X·Z 위치와 간격, 바닥 위 연결선 경로를 확인합니다.
    계통도 · 전력 연결 관계
    대지·건물·층 전체의 설비가 어떻게 연결되는지 카드와 화살표로 확인합니다.

    3D View 사용법

    • 빈 곳을 왼쪽 버튼으로 드래그하면 화면이 이동합니다. 오른쪽 버튼으로 드래그하면 시점이 회전합니다.
    • 건물을 선택하면 외형이 반투명해지고 층이 표시됩니다. 층 빌보드를 누르면 해당 층으로 진입합니다.
    • 설비를 선택해 우측 정보를 확인하고, 이동 핸들로 위치를 조절합니다. 모델 배치와 연결선 경로 편집도 이 화면에서 합니다.

    평면도 사용법

    • 현재 공간을 위에서 내려다봅니다. 빈 곳을 드래그해 이동하며 화면 회전은 하지 않습니다.
    • 설비의 가로·세로 범위를 보며 위치와 간격을 맞춥니다. 설비 배치와 연결선 경로 편집도 가능합니다.
    • 높이와 층 사이의 관계는 3D View로 전환해 확인하세요.

    계통도 사용법

    카드와 연결선 읽기

    • 카드는 실제 위치와 관계없이 연결 단계별로 자동 정렬됩니다. 카드에는 설비 이름, 코드 또는 종류, 소속 공간이 표시됩니다.
    • 같은 단계(열)는 같은 카드 색상입니다. 검색·직접 연결 필터를 적용하면 표시되는 단계에 맞춰 색상도 바뀝니다.
    • 계층 기본 연결과 추가 연결은 모두 점선입니다. 연결선 색상은 3D View·평면도의 설정을 따르며, 여러 선분의 색상은 순서와 길이 비율로 표시됩니다.
    • 화살표는 등록된 연결 방향입니다. 실시간 전력 흐름이나 전력량을 뜻하지 않습니다. 같은 높이에서 다른 카드가 막지 않으면 직선으로 연결합니다.

    설비 찾기와 연결 확인

    • 이름·코드·공간으로 검색합니다. 검색 결과에 양쪽 설비가 모두 있을 때 연결선을 표시합니다.
    • 카드를 선택하면 테두리와 직접 연결된 선이 강조되고, 관련 없는 카드는 흐려집니다. 우측 패널에서 상위·하위 연결을 관리할 수 있습니다.
    • ‘선택 설비의 직접 연결만’을 켜면 선택한 설비와 바로 연결된 설비만 표시합니다. 빈 곳을 클릭하면 선택이 해제됩니다.
    • ‘배치에서 보기’를 누르면 선택한 설비가 있는 3D 공간으로 이동합니다.

    계통도는 연결 관계를 자동 배치하는 화면입니다. 카드 위치를 직접 옮기거나 선을 드래그해 경로를 편집하지 않습니다. 실제 모델 배치와 경로 편집은 3D View·평면도에서 진행하세요.

    세 모드의 공통 화면 조작

    • 화면 이동: 빈 곳을 왼쪽 버튼으로 드래그합니다.
    • 확대·축소: 휠 또는 + / − 버튼을 사용합니다.
    • 전체 보기: 상단 네 모서리 아이콘 또는 F 키를 누릅니다. 계통도에서는 현재 표시된 카드를 화면에 맞춥니다.
    • 패널 너비: 좌우 경계선을 드래그합니다. 더블클릭하면 초기화됩니다.

    배치 화면의 인디케이터와 빌보드

    • 인디케이터: 3D View·평면도 상단에 현재 대지·건물·층 경로를 표시합니다. 이름을 누르면 해당 공간으로 이동합니다.
    • 대지에서는 홈 아이콘이 표시됩니다. 건물·층에서는 뒤로가기 버튼으로 한 단계 위로 이동합니다.
    • 빌보드: 태그 아이콘(빌보드 표시)으로 설비 빌보드를 켜거나 끕니다. 층 선택용 빌보드는 유지됩니다. 층 설비의 빌보드는 해당 층에 진입해야 표시됩니다.

    05 에셋과 설비 배치

    모델 등록과 배치

    • ‘에셋 등록’에서 종류를 정하고 GLB 파일을 선택합니다. 텍스처가 포함된 25 MB 이하 파일을 사용하세요.
    • 미리보기에서 이름과 실제 크기를 확인한 뒤 등록합니다. 에셋 등록은 로컬 서버에서 가능합니다.
    • 하단 썸네일을 선택한 뒤 바닥을 클릭하거나, 썸네일을 작업 화면으로 드래그해 배치합니다.
    • 층 안에 배치하려면 먼저 해당 층으로 진입하세요. Esc 키로 배치 모드를 종료합니다.

    선택과 수정

    • 설비나 빌보드를 클릭하면 우측에 정보가 표시됩니다. 좌측 목록에서도 선택할 수 있습니다.
    • 작업창이나 좌측 목록에서 Ctrl(⌘)+클릭으로 여러 설비를 선택합니다. 좌측 목록에서는 Shift 클릭으로 범위를 선택할 수도 있습니다.
    • 여러 설비를 선택하면 공통 중심에 기즈모가 나타납니다. X·Z 화살표나 중앙 사각형으로 함께 이동하고, ↻ 90° 버튼으로 중심을 기준으로 회전합니다. 드래그 중 Esc로 취소할 수 있습니다.
    • 같은 공간의 설비를 2개 이상 선택하면 작업창 우측 상단의 정렬 버튼이 활성화됩니다. 수평은 Z 좌표, 수직은 X 좌표를 선택 설비들의 중심에 맞춥니다. 정렬 후 겹침을 확인하세요. 계통도에서는 사용할 수 없습니다.
    • 선택 표시의 화살표는 한 축 이동, 사각형은 X·Z 동시 이동입니다. 회전 버튼은 90°씩 돌립니다.
    • 숫자를 직접 입력하거나 입력칸 옆 ↔ 핸들을 드래그합니다. ‘비율 고정’을 켜면 크기 비율을 유지합니다.
    • 이름은 Enter로 적용합니다. 위치·회전·크기는 즉시 반영됩니다. ‘복제’와 ‘삭제’는 우측 패널에서 실행합니다.

    06 건물과 층

    건물 배치와 층 등록

    • 건물 에셋을 대지에 배치하고 위치·회전·크기를 정합니다. 층이 등록된 건물은 크기를 바꿀 수 없습니다.
    • 건물을 선택하고 ‘층 등록·수정’을 엽니다. 지상층 수와 지하층 수를 입력합니다.
    • ‘옥상 사용’을 켜면 지상층의 맨 위층이 옥상이 됩니다. 예: 지상 4층이면 4층이 옥상입니다.
    • 각 층의 이름과 모델을 지정합니다. ‘기본 층’을 쓰거나, 하단 층 탭에 미리 등록한 에셋을 선택합니다.
    • 전체 층 X·Z 위치와 각 층 크기를 조절합니다. 크기는 건물 범위와 층간 간격 안에서 제한됩니다.
    • 옥상 바닥 높이를 조절하면 다른 층 간격이 자동 계산됩니다. 미리보기의 ‘건물 투명도’로 외형을 비교하세요.
    • ‘층 등록 완료’를 눌러 적용합니다. ‘취소’하면 등록 창의 변경을 취소합니다.

    건물 보기와 층 진입

    • 건물을 선택하면 외형이 반투명해지고 등록된 층이 표시됩니다. 층 빌보드를 클릭하면 해당 층으로 진입합니다.
    • 건물 빌보드는 파란색, 층 빌보드는 보라색입니다. 층 설비의 빌보드는 해당 층에 들어가야 표시됩니다.
    • 층 정보 패널은 조회와 삭제에 사용합니다. 이름·모델·크기 등은 건물의 ‘층 등록·수정’에서 바꿉니다.
    • 층을 삭제하면 그 층의 설비도 함께 삭제되고 층 간격이 다시 계산됩니다. 확인 팝업의 내용을 확인하세요.

    07 계층과 전력 연결

    계층으로 만드는 기본 연결

    좌측 목록에서 설비를 다른 설비 아래로 드래그하면 상하위 관계가 생기고 연결선이 자동 생성됩니다. 층 또는 다른 층의 설비 아래로 옮기면 소속 공간도 함께 이동합니다.

    위치를 유지하는 추가 연결

    • 상위 연결 추가: 선택한 대상 → 현재 설비 방향으로 연결합니다.
    • 하위 연결 추가: 현재 설비 → 선택한 대상 방향으로 연결합니다.
    • 다른 층·대지·다른 건물의 설비도 검색해 선택할 수 있습니다. 추가 연결은 기존 계층과 위치를 유지합니다.
    • 추가 연결은 ‘해제’로 제거합니다. ‘계층 연결’은 좌측 계층에서 상위 설비를 바꿔야 변경됩니다.

    다른 공간과 연결된 경우

    층 내부에서는 연결선이 층 바깥으로 뻗고, 끝에 대상 설비의 빌보드가 표시됩니다. 빌보드를 클릭하면 대상 설비의 공간으로 이동합니다.

    08 연결선 편집

    3D View 또는 평면도에서 실제 연결선 경로를 편집합니다.

    • 연결선을 선택하면 우측에 편집 항목이 표시됩니다. 지름과 선택 선분의 색상을 조절할 수 있습니다.
    • 포인트나 선분의 조작 핸들을 드래그해 경로를 바꿉니다. Shift를 누르면 자동 정렬을 해제합니다.
    • ‘코너 추가’ 또는 ‘선분에 포인트 추가’로 꺾임을 만듭니다. 설비에 고정된 끝점은 이동·삭제할 수 없습니다.
    • 포인트 최적화: 불필요한 포인트를 정리합니다. 합쳐지는 구간의 색상이 달라질 수 있습니다.
    • 최적 경로로 정리: 설비와 다른 연결선을 고려해 경로를 다시 만듭니다. 수동 경로가 바뀌므로 팝업의 적용 범위를 확인하세요.
    • 경로 편집은 실행 취소·다시 실행으로 되돌리거나 재적용할 수 있습니다.
